# SULUH ISLAMI

This project follows the master prompt for a professional web app used by Penyuluh Agama Islam in Indonesia.

## Development plan

1. Needs analysis and project structure
2. Authentication, profile, database, and authorization
3. Sermon and counseling material generators
4. Activity logging and guidance group management
5. Automated reporting and recaps
6. Evidence upload, archive, and revision history
7. AI integration, validation, and prompt management
8. PDF, DOCX, XLSX export and printing
9. Testing, security hardening, and deployment

## Notes

- The current Phase 1 MVP is a working frontend prototype with demo AI logic.
- Real AI and Supabase integrations can be enabled through environment variables.
- This repo intentionally avoids placing secrets in frontend code.
